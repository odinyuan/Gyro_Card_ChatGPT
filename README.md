# Gyro Holographic Card Demo

This is a static demo prepared for GitHub Pages.

Files:
- `index.html`
- `assets/frame.png`
- `assets/background.png`
- `assets/creature.png`
- `assets/shadow.png`
- `assets/card-full.png`
- `.nojekyll`

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Go to **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait ~1 minute and open the generated URL.

## Notes
- GitHub Pages uses HTTPS, which is good for `DeviceOrientationEvent` on mobile Safari.
- On iPhone/iPad, tap **Enable Gyro** to grant motion permission.
- On desktop, move the mouse to simulate tilt.
